# 방어 테스트용 전사본 (가상 · 가짜 값)

업로드 화면의 방어 장면을 확인하는 파일이다. **모든 내용은 직접 만든 가상 데이터이고, 연락처는 누가 봐도 가짜인 값이다**
(전화번호 `010-0000-0000`, 이메일 `test@example.com`, 주민등록번호 형태 `000000-1000000`). 실제 인물·연락처가 아니다.

`npm test`가 이 파일들을 `lib/transcript.ts`의 검사에 통과시켜 아래 기대 결과가 나오는지 확인한다(`lib/testdata.test.mjs`).
화면에서는 txt 파일 선택으로 하나씩 올려 보면 된다.

| 파일 | 올리면 | 보이는 안내(일부) |
| --- | --- | --- |
| `01_빈파일.txt` | 막힘 | 파일이 비어 있습니다 |
| `02_공백만.txt` | 막힘 | 파일이 비어 있습니다 |
| `03_제한초과.txt` | 막힘 | 파일당 10,000자까지 올릴 수 있습니다(현재 …자) |
| `04_가짜연락처.txt` | 막힘 | 전화번호·이메일·주민등록번호 형태가 있습니다(줄 번호와 함께) |
| `05_화자형식오류.txt` | 막힘 | 화자는 '진행자' 또는 '참가자 A'처럼 … / 화자를 '참가자 A'로 써 주세요 |
| `06_번호건너뜀.txt` | 막힘 | 발언 ID는 A-01부터 순서대로 … 이 줄은 A-02이어야 합니다 |
| `07_참가자발언없음.txt` | 막힘 | 참가자 발언이 없습니다 |
| `08_여러줄발언.txt` | 막힘 | 모든 발언은 발언 ID로 시작해야 합니다. 여러 줄에 걸친 발언은 한 줄로 합쳐 주세요 |
| `09_긴텍스트.txt` | **저장됨** | 정상 파일이다. 참가자 Q로 저장되며, 공백 없는 긴 단어·긴 주소가 작은 화면에서 깨지지 않는지 볼 때 쓴다. 확인 뒤 목록에서 지운다 |

막히는 파일은 저장되지 않는다. 같은 검사를 브라우저(올리기 전)와 서버(저장 전)에서 한다.
