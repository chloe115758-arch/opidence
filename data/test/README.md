# 방어 테스트용 전사본 (가상 · 가짜 값)

업로드 화면의 방어 장면을 확인하는 파일이다. **모든 내용은 직접 만든 가상 데이터이고, 연락처는 누가 봐도 가짜인 값이다**
(전화번호 `010-0000-0000`, 이메일 `test@example.com`, 주민등록번호 형태 `000000-1000000`). 실제 인물·연락처가 아니다.

`npm test`가 이 파일들을 `lib/transcript.ts`의 검사에 통과시켜 아래 기대 결과가 나오는지 확인한다(`lib/testdata.test.mjs`).
화면에서는 txt 파일 선택으로 하나씩 올려 보면 된다.

| 파일 | 올리면 | 보이는 안내(일부) |
| --- | --- | --- |
| `01_빈파일.txt` | 막힘 | 파일이 비어 있습니다 |
| `02_공백만.txt` | 막힘 | 파일이 비어 있습니다 |
| `03_제한초과.txt` | 막힘 | 파일당 10,000자까지 올릴 수 있습니다(현재 …자) |
| `04_가짜연락처.txt` | 막힘 | 전화번호·이메일·주민등록번호 형태가 있습니다(줄 번호와 함께) |
| `05_화자형식오류.txt` | 막힘 | 화자는 '진행자' 또는 '참가자 A'처럼 … / 화자를 '참가자 A'로 써 주세요 |
| `06_번호건너뜀.txt` | 막힘 | 발언 ID는 A-01부터 순서대로 … 이 줄은 A-02이어야 합니다 |
| `07_참가자발언없음.txt` | 막힘 | 참가자 발언이 없습니다 |
| `08_여러줄발언.txt` | 막힘 | 모든 발언은 발언 ID로 시작해야 합니다. 여러 줄에 걸친 발언은 한 줄로 합쳐 주세요 |
| `09_긴텍스트.txt` | **저장됨** | 정상 파일이다. 참가자 Q로 저장되며, 공백 없는 긴 단어·긴 주소가 작은 화면에서 깨지지 않는지 볼 때 쓴다. 확인 뒤 목록에서 지운다 |
| `10_정상_라벨R.txt` | **저장됨** | 짧은 정상 파일(참가자 R). 10건 제한 확인용 |
| `11_정상_라벨S.txt` | 저장됨 (이미 10건이면 막힘) | 짧은 정상 파일(참가자 S). 10건 제한 확인용 |
| `12_중복_라벨R.txt` | 저장됨 (R이 이미 있으면 "이미 있습니다") | 참가자 R의 다른 파일. `10`과 함께 올려 "같은 참가자 두 개"를 확인할 때 쓴다 |

한 줄이 여러 개인정보 형태에 걸려도(예: `000000-1000000`) 안내는 한 줄에 하나로 합쳐 보인다(`04_가짜연락처.txt`의 6번째 줄은 "주민등록번호·전화번호 형태가 있습니다").

**10건 제한(11번째 차단) 확인**: 시크릿 창에서 샘플 8건 → `09` → `10` → `11` 순서로 올린다. 샘플 8건 + 09 + 10 = 10건이므로 `11`(참가자 S)이 11번째가 되어 "전사본은 10건까지 올릴 수 있습니다" 안내와 함께 막혀야 한다. 확인 뒤 올린 전사본은 목록에서 지운다.

막히는 파일은 저장되지 않는다. 같은 검사를 브라우저(올리기 전)와 서버(저장 전)에서 한다.

## 여러 파일을 한 번에 올릴 때의 기대 결과 (`lib/batch.test.mjs`가 확인한다)

고른 파일 수가 남은 자리(10 − 올라간 건수)보다 많으면 아무것도 올리지 않는다. 그렇지 않으면 고른 순서대로 한 개씩 저장한다.

| 상황 | 기대 결과 |
| --- | --- |
| 빈 작업 공간에서 `01`~`09` 9개 | **"1건 저장, 8건 실패"**. `09`(참가자 Q)만 저장되고, `01`~`08`은 각각 위 표의 안내가 파일 이름과 함께 나온다 |
| 샘플 8건이 있는 상태에서 `01`~`09` | "2건만 더 올릴 수 있습니다. 파일을 9개 골랐으니 7개를 빼고…" 아무것도 저장하지 않는다 |
| 자리가 0인 상태에서 파일 선택 | "더 올릴 자리가 없습니다" 아무것도 저장하지 않는다 |
| `10`과 `12`(둘 다 참가자 R) | "1건 저장, 1건 실패". `12`는 "참가자 R 전사본이 이미 있습니다" |
| `09`·`10`·`11` | "3건 저장" |
| `interview_A.txt`를 샘플이 있는 상태에서 | "0건 저장, 1건 실패" — "이미 있습니다" |
