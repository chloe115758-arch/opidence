# Opidence 가상 인터뷰 데이터셋 v1

- 주제: 공공자전거 앱 이용 경험
- 구성: 참가자 A~H, 8건, 한국어
- 모든 인터뷰는 직접 만든 가상 데이터다. 실제 인물, 실제 발언, 실제 서비스 운영 정보가 아니다.
- 서비스 이름은 특정하지 않고 "공공자전거 앱"으로만 쓴다.

## 파일
- interview_A.txt ~ interview_H.txt: 인터뷰 전사본 8건

## 발언 ID 규칙
- 모든 줄은 "참가자 라벨-순번" ID로 시작한다. 예: A-04
- 진행자 질문에도 ID가 붙지만, 근거로 인정하는 것은 참가자 발언뿐이다.
- 근거 인용은 "A-04"처럼 ID로 가리킨다. 정답 라벨과 근거 일치율 측정에 그대로 쓴다.
